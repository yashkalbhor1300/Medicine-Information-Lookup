# 💊 Medicine Information Lookup

## Overview
Medicine Information Lookup is a Python-based web application that allows users to search and explore general information about medicines using a structured CSV dataset.

The application provides a simple interface to retrieve medicine details, including composition, therapeutic classification, uses, benefits, side effects and safety information.

## Features
- Search medicines by name.
- Case-insensitive partial search.
- Word-based fallback search.
- View medicine composition and classification.
- Explore uses, benefits and side effects.
- View medicine usage information.
- Display safety information.
- Access original information through available source links.
- Handle missing datasets and unsuccessful searches.

## Technologies Used
- Python
- Streamlit
- Pandas
- HTML
- CSS
- CSV Dataset
